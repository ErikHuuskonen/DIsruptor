# Mushroom / Fungi Universal Survival Strategy Schema

## 1. Universal rule
**"Grow the network to where the food is, digest it outside, absorb it inside."**
A fungus does not hunt and does not hide inside one host. It spreads an invisible network (mycelium) through its environment, breaks down what others cannot digest, and trades with partners. The visible mushroom is only the fruit; the real organism is the network underground.

## 2. Shared functions
Core problem: food is locked in tough, scattered material (wood, leaves, soil, rock), the fungus cannot move, and competitors (bacteria, other fungi) want the same resources.
Functions: colonization, network expansion, external digestion, exchange, reproduction & dispersal.

## Master Loop
```
A → B → C → D → F → E
↑_______________________↑
   repeats on new substrate

G runs underneath all stages: when conditions turn bad, persist and wait.
```

```

b. germination
   i.   substrate sensing
   ii.  moisture / temperature trigger
   iii. germ tube emergence
   iv.  surface adhesion

c. penetration
   i.   enzymatic surface breaking
   ii.  mechanical pressure
   iii. natural opening entry
   iv.  wound / dead tissue exploitation

d. establishment
   i.   first hyphal anchoring
   ii.  local resource tap
   iii. microenvironment acidification
   iv.  territory claim
```

## C. EXTERNAL DIGESTION
```
a. secretion
   i.   enzyme release outward
   ii.  acid release

   iv.  oxidative attack

b. breakdown
   i.   cellulose decomposition

c. absorption
```

## G. PERSISTENCE (runs underneath all stages)
```
a. dormancy (spores, hardened survival structures)
b. stress tolerance (drought, cold, toxins)
c. regrowth from fragments
d. extreme longevity (networks living for millennia)
```

---

## 5. Gap analysis
Missing from A–E, added as F and G:
- **F. Defense & competition** — A–E assumed the fungus is alone on the substrate. Bacteria and rival fungi fight for the same food.
- **G. Persistence** — a fungus cannot move away from bad conditions. It survives by waiting. This is not a step in the loop but a mode that can switch on at any stage.
